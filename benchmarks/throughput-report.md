## 关键发现

### 1. 🚀 q8_0 在长文本生成时性能最佳

- **200 tokens**: 218.69 tok/s（比 f16 快 **48.5%**！）
- **内存节省**: 47% (384MB → 204MB)
- **质量**: 接近 f16，几乎无损
- **结论**: **最佳性价比选择**

### 2. ⚡ 短文本生成性能接近

- f16 vs q8_0: 几乎相同（232 vs 237 tok/s）
- q4_0 略慢但仍可接受（172 tok/s）

### 3. 📉 f16 在长文本生成时性能下降

- 50 tokens: 232.60 tok/s
- 200 tokens: 147.29 tok/s（**下降 37%**）
- **原因**: KV cache 内存带宽瓶颈

### 4. 💾 q4_0 内存优势明显

- **内存节省**: 72% (384MB → 108MB)
- **性能**: 162-179 tok/s（可接受）
- **适合**: 内存受限场景

## 智能策略建议

使用 threshold 策略自动切换:

```json
{
  "name": "threshold",
  "params": {
    "thresholds": [
      {"ctx_utilization": 0.3, "level": "f16"},
      {"ctx_utilization": 0.7, "level": "q8_0"},
      {"ctx_utilization": 0.9, "level": "q4_0"}
    ],
    "hysteresis": 0.05
  }
}
```

**逻辑**:
- Context < 30%  → f16   (低负载，追求极致)
- Context < 70%  → q8_0  (正常负载，最佳平衡)
- Context ≥ 70% → q4_0  (高负载，节省内存)
